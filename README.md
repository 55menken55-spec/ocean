# 🌊 Большой Барьерный риф — 3D-симуляция океанического шельфа

Масштабный интерактивный 3D-мир (2.4 × 2.4 км) с реалистичной географией шельфа **Большого Барьерного рифа** от прибрежных мангров и лугов морской травы до гребня рифа, затопленной Голубой дыры и отвесного обрыва в бездну Кораллового моря.

Архитектура построена на расширяемой **платформе водных биомов планеты** (`OC.Biomes`), позволяющей в будущем добавлять любые океанические зоны Земли (леса ламинарии, Марианскую впадину, арктические льды, гидротермальные источники и др.) с единым оптимизированным движком чанкового стриминга.

## География Большого Барьерного рифа (6 зон шельфа)

| Зона | Глубина | Характерные особенности |
|---|---|---|
| **Мангровые отмели** | `0 – 5 м` | Западная береговая кромка с арочными ходульными корнями *Rhizophora* и тёплой изумрудной водой |
| **Луга морской травы** | `4 – 12 м` | Солнечные песчаные отмели с коврами *Zostera / Halophila*, пастбище дюгоней и черепах |
| **Внутренняя лагуна и Островок** | `0 – 22 м` | Бирюзовая лагуна с надводным коралловым песчаным островком (Sand Cay) и 18 коралловыми башнями-бомми *Porites* |
| **Гребень рифа и желоба прибоя** | `2 – 20 м` | Реалистичная геоморфология *spur-and-groove*: параллельные коралловые контрфорсы и белые песчаные канавы |
| **Внешний склон, Проход и Голубая дыра** | `22 – 88 м` | Глубокий приливный Рифовый проход и карстовый провал Голубой дыры глубиной `88 м` с уступами |
| **Отвесная стена и Бездна Кораллового моря** | `40 – 168 м` | Крутой известняковый обрыв шельфа в глубокую сумеречную бездну Кораллового моря |

## Флора и фауна (42+ объекта в интерактивном Атласе)

- **19 типов процедурной флоры и бентоса (InstancedMesh):** ветвистые *Acropora*, столовидные кораллы, мозговые кораллы, массивные *Porites*-бомми, глубоководные пластинчатые кораллы *Montipora*, веерные горгонарии, мягкие *Dendronephthya*, чёрные кораллы бездны, трубчатые и гигантские бочковидные губки, актинии, гигантские тридакны *Tridacna gigas*, морская трава, ламинария, красные мангры, морские ежи *Diadema*, звёзды *Linckia* и «терновый венец», спиральные раковины «тритонов рог».
- **14 стай рыб с GPU-анимацией хвостового плавания (`aSwim`):** голубые хирурги, жёлтые танги, сардинеллы, хромисы, рыбы-клоуны, рыбы-бабочки, мавританские идолы, рыбы-попугаи и вихри барракуд.
- **Мегафауна и одиночные виды:** дюгони, зелёные черепахи, синепятнистые хвостоколы, пятнистые орляки, гигантские манты, темнопёрые рифовые акулы, китовая акула, горбатый кит, крылатки-зебры, рифовые осьминоги, гигантские мурены и биолюминесцентные медузы.

## Оптимизация и структура проекта

Проект спроектирован для **мгновенного старта (< 0.3 с)** и плавных **60 FPS** на карте 2.4 × 2.4 км:
- **Прогрессивный чанковый рельеф (LOD):** 256 чанков (`150 × 150 м`) с непрерывными нормалями и юбками по краям (без швов между разными LOD), потоковая подгрузка по `3.5 мс/кадр`.
- **Чанковый стриминг флоры (`InstancedMesh`):** общие геометрические прототипы переиспользуются пулами инстансов (~38 draw calls на тысячи колоний).
- **Бесконечные частицы (GPU wrap):** пузыри и биолюминесцентный планктон зациклены вокруг камеры в вершинном шейдере.
- **4 профиля качества (`Низкое` / `Среднее` / `Высокое` / `Ультра`):** меняются на лету без перезагрузки.

### Исходный код

```
src/
├── core/
│   ├── util.js              # Детерминированный PRNG, 2D-шум (FBM/ridged), слияние геометрий
│   ├── quality.js           # Профили качества (Low/Medium/High/Ultra)
│   └── biome_registry.js    # Реестр водных биомов планеты (OC.Biomes)
├── biomes/
│   └── great_barrier_reef.js # География, батиметрия, флора и энциклопедия GBR
├── engine/
│   ├── world.js             # Рендер, вода со Снеллиусом, каустика, прожектор, оптика по глубине
│   ├── terrain.js           # Потоковый LOD-ландшафт с юбками
│   ├── flora_library.js     # Процедурная библиотека 19 видов кораллов, растений и бентоса
│   ├── flora_streamer.js    # Стриминг флоры по чанкам в пулы InstancedMesh
│   ├── fauna_engine.js      # Стаи рыб, мегафауна, медузы и камерные частицы
│   └── audio.js             # Процедурный WebAudio океан с адаптацией под глубину и зону
└── ui/
    ├── navigation.js        # Свободное плавание + Орбита + Тур + плавный перелёт
    ├── minimap.js           # Интерактивная батиметрическая мини-карта
    ├── atlas.js             # Интерактивный Атлас рифа
    └── main.js              # Инициализация, телеметрия и игровой цикл
```

### Сборка и проверка

```bash
# Собрать автономный оффлайн index.html (работает даже без сервера)
python3 build.py

# Запустить локальный сервер
python3 -m http.server 8080 --bind 0.0.0.0

# Запустить автоматическую проверку географии, шейдеров и стриминга
node tests/verify.mjs

# Проверить валидность всех Agent Skills (.agents/skills/)
python3 .agents/skills/validate_skills.py
```
